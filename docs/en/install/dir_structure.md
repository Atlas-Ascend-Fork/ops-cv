# Project Directory

> Some directories listed in this chapter are optional. Refer to the actual deliverables. In particular, the **single operator directory** may differ across scenarios. Details are as follows:
>
> - If the op_host directory is missing, the operator may call the op_host implementation of another operator. For the call logic, see the source code implementation in the op_api or op_graph directory of that operator. Alternatively, the Kernel may not have an Ascend C implementation yet. If needed, developers are welcome to contribute the operator by referring to the [contribution guide](../../../CONTRIBUTING.md).
> - If the op_kernel directory is missing, the operator may call the op_kernel implementation of another operator. For the call logic, see the source code implementation in the op_api or op_graph directory of that operator. Alternatively, the Kernel may not have an Ascend C implementation yet. If needed, developers are welcome to contribute the operator by referring to the [contribution guide](../../../CONTRIBUTING.md).
> - If the op_api directory is missing, the operator does not support aclnn calls yet.
> - If the op_graph directory is missing, the operator does not support graph mode calls yet.

The full project directory hierarchy is described as follows:

```cpp
├── cmake                                               # project compilation directory
│   ├── aclnn_ops_cv.h.in                               # aclnn aggregate header file template
│   └── ...
├── common                                              # project common header files and common code
│   ├── CMakeLists.txt
│   ├── inc                                             # common header file directory
│   └── src                                             # common code directory
├── experimental                                        # directory for user-defined custom operators
│   ├── image                                           # optional, directory for user-developed image operators
│   │   └── CMakeLists.txt
│   └── objdetect                                       # optional, directory for user-developed objdetect operators
│       └── CMakeLists.txt
├── ${op_class}                                         # operator category, such as image and objdetect operators
│   ├${op_name}                                         # operator project directory, ${op_name} indicates the operator name (lowercase with underscores)
│   │   ├── CMakeLists.txt                              # operator cmakelist entry
│   │   ├── README.md                                   # operator introduction document
│   │   ├── docs                                        # operator document directory
│   │   │   └── aclnn${OpName}.md                       # operator aclnn API introduction document, ${OpName} indicates the operator name (upper camel case)
│   │   ├── examples                                    # operator call example directory
│   │   │   ├── test_aclnn_${op_name}.cpp               # example of calling the operator through aclnn
│   │   │   └── test_geir_${op_name}.cpp                # example of calling the operator through geir
│   │   ├── op_graph                                    # graph fusion related implementation
│   │   │   ├── CMakeLists.txt                          # op_graph cmakelist file
│   │   │   ├── ${op_name}_graph_infer.cpp              # InferDataType file, implements operator data type inference
│   │   │   ├── ${op_name}_proto.h                      # operator prototype definition, used to identify the operator during graph optimization and fusion
│   │   │   └── fusion_pass                             # operator fusion rule directory
│   │   ├── op_host                                     # Host-side implementation
│   │   │   ├── CMakeLists.txt                          # Host-side cmakelist file
│   │   │   ├── config                                  # optional, binary configuration file, automatically generated by the project if not configured
│   │   │   │   ├── ${soc_version}                      # binary information configured for the operator on the NPU, ${soc_version} indicates the NPU model
│   │   │   │   │   ├── ${op_name}_binary.json          # operator binary configuration file
│   │   │   │   │   └── ${op_name}_simplified_key.ini   # operator SimplifiedKey configuration information
│   │   │   │   └── ...
│   │   │   ├── ${op_name}_def.cpp                      # operator information library, defines basic operator information such as name, input and output, and data type
│   │   │   ├── ${op_name}_infershape.cpp               # optional, InferShape implementation, infers the output shape based on the operator shape; if not configured, the output shape is the same as the input shape
│   │   │   ├── ${op_name}_tiling_${sub_case}.cpp       # optional, Tiling optimization for certain sub-scenarios, ${sub_case} indicates the sub-scenario, for example ${op_name}_tiling_arch35 is the optimization for the arch35 architecture; if this file is absent, the operator has no specific Tiling strategy for the corresponding sub-scenario; note: the Tiling implementation file name must contain the `_tiling` identifier to be recognized by the compilation system and participate in compilation
│   │   │   ├── ${op_name}_tiling_${sub_case}.h         # optional, header file for the Tiling implementation in the ${sub_case} sub-scenario
│   │   │   ├── ${op_name}_tiling.cpp                   # optional, if this file is absent, there is no Tiling implementation in the corresponding scenario (divides the tensor into multiple small blocks and performs parallel computation by data type)
│   │   │   ├── ${op_name}_tiling.h                     # optional, header file for the Tiling implementation
│   │   │   └── CMakeLists.txt                          # Host-side cmakelist file
│   │   ├── op_api                                      # optional, operator aclnn implementation file directory, automatically generated by the project if not configured
│   │   │   ├── aclnn_${op_name}.cpp                    # operator aclnn API implementation file
│   │   │   ├── aclnn_${op_name}.h                      # operator aclnn API implementation header file
│   │   │   ├── ${op_name}.cpp                          # operator l0 API implementation file
│   │   │   ├── ${op_name}.h                            # operator l0 API implementation header file
│   │   │   └── CMakeLists.txt
│   │   │── op_kernel                                   # AI Core operator Device-side Kernel implementation
│   │   │   ├── ${sub_case}                             # optional, directory used by the ${sub_case} sub-scenario
│   │   │   │   ├── ${op_name}_${model}.h               # operator kernel implementation file, ${model} indicates the user-defined file name suffix, usually the Tiling template name
│   │   │   │   └── ...
│   │   │   ├── ${op_name}_tiling_key.h                 # optional, TilingKey file, defines the Key of the Tiling strategy and identifies different partition methods; if not configured, the operator has no corresponding Tiling strategy
│   │   │   ├── ${op_name}_tiling_data.h                # optional, TilingData file, stores Tiling strategy related configuration information such as block size and parallelism; if not configured, the operator has no corresponding Tiling strategy
│   │   │   ├── ${op_name}.cpp                          # Kernel entry file, contains the main function and scheduling logic
│   │   │   └── ${op_name}.h                            # Kernel implementation file, defines the Kernel header file, contains function declarations, structure definitions, and logic implementation
│   │   │── op_kernel_aicpu                             # optional, AI CPU operator Device-side Kernel implementation
│   │   │   ├── ${op_name}_aicpu.cpp                    # Kernel entry file, contains the main function and scheduling logic
│   │   │   └── ${op_name}_aicpu.h                      # Kernel header file, contains function declarations, structure definitions, and logic implementation
│   │   └── tests                                       # operator test case directory
│   │       ├── CMakeLists.txt
│   │       └── ut                                      # optional, UT test cases, develop corresponding test cases based on actual conditions
│   │           ├── CMakeLists.txt                      # UT test case cmakelist file
│   │           ├── op_graph                            # op_graph test case directory
│   │           │   ├── CMakeLists.txt
│   │           │   └── fusion_pass                     # fusion rule test case directory
│   │           │       └── CMakeLists.txt
│   │           ├── op_host                             # op_host test case directory
│   │           │   ├── CMakeLists.txt
│   │           │   ├── ${op_name}_regbase_tiling.h
│   │           │   ├── op_api                          # op_api test case directory
│   │           │   │   ├── CMakeLists.txt
│   │           │   │   └── test_aclnn_${op_name}.cpp   # operator aclnn test case file
│   │           │   ├── test_${op_name}_${sub_case}.cpp # op_host test case file in the ${sub_case} sub-scenario
│   │           │   ├── test_${op_name}.cpp             # op_host test case file
│   │           │   ├── test_${op_name}_infershape.cpp  # operator InferShape test case file
│   │           │   └── test_${op_name}_tiling.cpp      # operator Tiling test case file
│   │           └── op_kernel                           # op_kernel test case directory
│   │               ├── CMakeLists.txt
│   │               │── test_${op_name}.cpp             # operator Kernel test case file

│   │                   ├── compare_data.py             # data script
│   │                   └── gen_data.py                 # data generation script
│   └── ...
├── docs                                                # project related document directory
├── examples                                            # end-to-end operator development and call examples
│   ├── add_example                                     # AI Core operator example directory
│   │   ├── CMakeLists.txt                              # operator compilation configuration file
│   │   ├── examples                                    # operator usage example directory
│   │   ├── op_graph                                    # operator graph construction related directory
│   │   ├── op_host                                     # operator information library, Tiling, and InferShape related implementation directory
│   │   ├── op_kernel                                   # operator Kernel directory
│   │   └── tests                                       # operator test case directory

│   │   ├── CMakeLists.txt                              # operator compilation configuration file

│   │   └── tests                                       # operator test case directory
```

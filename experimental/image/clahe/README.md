## 功能说明

- 算子功能：

  实现单通道图像的限制对比度自适应直方图均衡化（CLAHE），通过限制局部对比度增益，抑制图像背景噪声的过度放大。

- 计算逻辑：

  - 按 `tile_grid_size` 将每幅图像划分为局部网格，分别统计直方图。
  - 按 `clip_limit` 裁剪直方图，将超额计数均匀分配，再按步长分配剩余计数。
  - 计算各网格的累计分布映射，并按相邻网格中心进行双线性插值。
  - 网格不能整除图像时，按 OpenCV CLAHE 的规则在右侧和底部做 REFLECT_101 扩展。

## 参数说明

| 参数名 | 输入/输出/属性 | 描述 | 数据类型 |
|-|-|-|-|
| x | 输入 | 单通道图像，支持 `[H,W]`、`[N,H,W]`、`[N,1,H,W]`，数据格式为 ND | UINT8、UINT16 |
| clip_limit | 属性 | 对比度裁剪参数，默认 40；有限非正值关闭裁剪 | FLOAT |
| tile_grid_size | 属性 | 横向、纵向网格数量，默认 `[8,8]`，两个正整数 | LIST_INT |
| y | 输出 | CLAHE 处理结果，数据格式为 ND | 与 x 一致 |

## 约束说明

- x 支持 rank 2、3、4；rank 4 时通道数必须为 1。
- N 的范围为 1～256，H、W 必须为正数，支持运行时尺寸变化。
- y 的 shape、数据类型与 x 一致，输入、输出均为 ND；输出应独立分配。
- clip_limit 必须为有限 float32 值，不支持 NaN 或 Inf；正值按 tile 面积和 bin 数归一化，裁剪计数下界为 1。
- tile_grid_size 必须包含两个正整数，依次表示横向和纵向网格数量。
- uint8、uint16 分别使用完整的 256、65536 个 bin，不进行灰度位移。参考语义为 OpenCV 4.13.0 CLAHE，bit shift 为 0。
- 若任一轴不能整除网格，两轴均进入扩展分支；已整除的另一轴也会增加一个网格单位。
- 网格乘积、扩展后的尺寸及 tile 面积须处于 int32 正数范围；总元素数和 workspace 大小须处于 int64 范围，实际可分配规模取决于设备内存。
